# Cost plan

The foundation targets no additional paid subscriptions: public GitHub source, GitHub Pages and local dependency-free tooling. Actual account limits and hosting behavior must be verified; free does not imply unlimited or permanent capacity.

S1 targets local/static processing with no required cloud accounts, paid inference, automatic uploads or media recording. Use the existing computer and entitled developer tools. Actual device/runtime suitability remains a measured gate.

Later online costs include compute, bandwidth, storage/backups, media transport, monitoring, age/guardian processing, legal/privacy work and moderation/incident coverage. An operating ceiling, named payer and safe quota exhaustion behavior are required before paid services. Temporary credits are experimental resources, not a sustainable baseline. See [operating plan](OPERATING-PLAN.md).
