# Roadmap

The public progress site reads [structured status](../../data/project-status.json). This document explains the order; Issues hold scoped tasks. Dates and completion percentages are intentionally unpromised.

| Stage | Outcome | Current state |
| --- | --- | --- |
| F0 Community foundation | Consolidated source, public/local Git, Desktop workflow, contributor guidance and Pages progress | Current work; verify remote/CI/site separately |
| S1 Local creator prototype | Shared SDK, dual authoring, interpreted guest runtime, two original worlds and recoverable local personalization/travel | Planned; no application implementation |
| S2 Shared rooms/text | Authoritative social state and changed-client access tests | Planned |
| S3 Voice | World/proximity/party routing, lifecycle, quota and forbidden-delivery tests | Planned |
| S4 Trusted publishing | Automated validated releases, current grants, rollback/quarantine/revocation | Planned |
| S5 Public readiness | Reviewed age/guardian/country/data/rights policy and sustainable staffed operations | Blocked on readiness evidence |

AI/personas, economy, pets, federation and broad native/XR support remain later scope. Internal tests do not replace the intended public release. See [v0.1](V0.1-SPEC.md) and [public-release gates](PUBLIC-RELEASE.md).
