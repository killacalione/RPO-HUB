# Data and persistence

The foundation has no application database or visitor submissions. Its public status is versioned JSON in Git. GitHub hosts contributor activity according to its own policies. The static site uses no cookies, analytics, storage or tracking scripts; GitHub hosting request handling remains separate from application behavior.

S1 proposes local project/draft storage and export/import. Immutable template/source and validated personal configuration remain separate; requested visibility grants no real ownership or online access. Only mark a save complete after its storage transaction succeeds; invalid imports must preserve the last good draft.

Before online data storage, each contract identifies source of truth, controller/processor, access rules, retention, deletion/export and cross-border transfers. Keep raw identity documents, face/biometric data, payment secrets and wallet private keys outside the baseline. Actual necessity/legal design and processor agreements require explicit review. No schema or provider is selected from a template.
