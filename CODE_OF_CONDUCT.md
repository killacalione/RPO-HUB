# Community Code of Conduct

The Oasis welcomes respectful participation across backgrounds and experience levels. Help people learn, discuss evidence, give constructive feedback and respect personal boundaries.

Harassment, threats, hate, sexualized conduct, doxxing, impersonation, spam and sharing private or exploitative material are prohibited. Do not ask participants for ages, identity documents or sensitive personal details in public project channels. Keep all public project spaces appropriate for a broad audience.

This code applies to repository Issues, pull requests, Discussions and other spaces explicitly operated for this project. It governs this contributor community; it does not establish readiness of a future mixed-age application.

## Reports and enforcement

Use GitHub's **Report content** / **Report abuse** controls for harassment or private/sensitive reports. The project owner can review visible repository conduct, hide/remove harmful content, lock conversations or restrict participation. Maintainer behavior can be reported to GitHub. Do not publish sensitive evidence or retaliation in Issues.

Maintainers consider context, severity and repeated behavior. They may clarify expectations, warn, restrict or remove participation. Report handling is volunteer-run; no staffed response time or confidential project mailbox is promised. Use GitHub's appeal/support routes when appropriate.
